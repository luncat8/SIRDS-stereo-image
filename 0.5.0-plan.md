# 0.5.0 — chunked link rebuild (no worker)

Depends on 0.4.0. The animation frame is a gather, on the GPU when WebGL2 is available. The hitch
left is `buildLinks`: one pointer frame rebuilds every row, about 25 ms at 1280×800 and 40–90 ms on
a large viewport. A Web Worker is the wrong fix — Chrome blocks workers on `file://`, and this page
is opened that way.

## Goal

A period or depth drag must not freeze the image. Spread `linkRow` across frames, keep showing the
previous stereogram until the new map is complete, then upload once and draw.

## Non-goals

No new presets, textures or views. No worker, no `Blob` URL worker, no second copy of `linkRow`.
Do not rebuild links per animation frame. Do not drop HSR or the union-find.

## Shape

- Two link buffers, swapped when a rebuild finishes. The gather always reads the complete one.
- A rebuild walks rows from a cursor. Budget about 4 ms of `linkRow` per animation frame, then
  return. No `new` inside that slice — the second `Int32Array` is allocated with the resize buffers.
- While a rebuild is in flight, slider and drag writes update the *target* period/depth/HSR and set
  a restart flag. Do not present a half-written map.
- On completion: swap, `uploadLinks` once if the active renderer is WebGL2, draw one frame.
- A tiny canvas (the whole rebuild under ~4 ms) finishes in the same turn it started, so small
  views feel identical to today.
- Cancel cleanly on resize: drop the in-flight cursor, the new buffers are empty, `linksDirty`
  starts a fresh rebuild.

## Validation

- `verify-links.js` unchanged — it calls `linkRow` directly.
- Extend `gf-smoke.js`: after a period change, the next few `runFrame`s must end on a map that
  satisfies the new period (sample a row: linked pairs byte-equal, separation matches `periodAt`).
- A rebuild interrupted by a second period change must present only the second period, never a mix.
- Flat-surface HSR no-op and the 100% constraint bar still hold on the presented map.
- Dragging the period on a 1280×800 canvas must not call `linkRow` for every row inside one
  pointer frame. Log the rows-per-frame budget.

## Rollback

A `CHUNK_LINKS` flag that rebuilds every row in `buildLinks`, which is what 0.4 does.
