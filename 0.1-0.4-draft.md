# 0.1 – 0.4 roadmap — gf.html lightweight track

gf.html stays the product: single file, classic `<script>`, no modules, no build, `file://` friendly, 4-language flat i18n table (en/ru/cn/jp), `ResizeObserver` + absolutely-positioned canvases, `localStorage` settings, animated noise with stable seed and X/Y drift. Painting lives in `index.html` — never port it.

This roadmap splits the former monolithic 0.1.0 plan into four incremental, reviewable steps. Each step is lightweight, ships independently, and never ports heavy features from `index.html` or `ag.html`.

## Sources and stance

- `gf.html` — base. Keep its UX (guide-dot period slider, animation, i18n). Fix its defects, don't redesign it.
- `ag.html` — large vanilla SIRDS suite (classes, depth presets, tartan/blobs/tie-dye tiles, palettes, Thimbleby μ, HSR, shimmer/wiggle/anaglyph, reticle, export). Useful for content ideas and for the correct optical formulas, but its UI shell, class architecture, and injected Cloudflare script are not ported. Most of its preset/texture/view buffet is intentionally left out to keep gf lightweight.
- `implement-noise-and-brush-tools/` — React+Vite+Tailwind heightmap painter. **Not a SIRDS.** Its build setup, `FalloffTable`, brush stamping, `blurShade`, lit renderer (normals/Lambert/Blinn/tilt/AO), and `fillNoise` allocation pattern are not ported. Only its noise/height ideas are read as reference.
- `index.html` (WebGPU) — fast `sep/std/relax` compute pipelines, brush compute, `DepthMap`/`GpuEngine` classes, `StereoGUI` depth carving, shade map, ghost reduction. Heavy and deliberately not ported. Lightweight takeaways are distilled per plan; everything else is listed under Not ported.

## What counts as heavy (never port to gf.html)

Brushes / painting / `shade` map / `ghost` copies, `FalloffTable`, `heightmap.ts`/`renderer.ts` lit relief, WebGPU/WebGL compute pipelines, `StereoGUI` bevel carving, save/load webp maps, 5-swatch palette editors + presets (cyber/forest/…), iterative relaxation (iters 1..60, error back-propagation), tartan/tie-dye/confetti/wood/blob image tiles with zoom/palette/seed matrix. They stay in `index.html` / `ag.html`.

## What is taken lightweight (distilled findings only)

- Canvas wrapper with `position:absolute; inset:0` canvases to break layout→resize feedback (already in gf, keep).
- Depth as `Float32Array 0..1` single source of truth (replaces red-channel `ImageData` reads).
- Preallocated typed arrays / reuse outside the hot path (no `new` per row/frame).
- Grain quantization after drift (`floor((x-moveX)/grain)`), seeded `hashNoise`/`simplex3` vs `Math.random`.
- Geometry sized relative to `w,h` (not fixed pixels).
- `periodAt(z)` single helper for guide dots, status, and renderer.

## Milestones

### 0.1 — Foundation + defects + canvas drag (this repo: `0.1.0-plan.md`)
Defects fixed, preallocated buffers, drag `dX→period / dY→depth` on the canvas synced to the GUI sliders. CPU only, no new presets/textures/views.

### 0.2 — Lightweight depth content (`0.2.0-plan.md`)
Existing presets rewritten to scale, plus 1–2 cheapest pure-math presets (heart, ripples) and a custom-text field. Minimal post-process (invert + contrast; tiny blur with one scratch if included). Still no image upload.

### 0.3 — Stereo correctness polish (`0.3.0-plan.md`)
Union-find leftmost-root linking; linear `s = P − z·D` kept, Thimbleby deferred. Cheap HSR toggle. No new textures/palettes/anaglyph/wiggle/relief.

### 0.4 — Acceleration: WebGL2 with CPU fallback — next version (`0.4.0-plan.md`)
Abstract renderer `CPU | WebGL2` behind one interface. Feature-detect WebGL2 at startup, default to WebGL2, fallback to CPU. Pixel-identical output, file:// safe, persisted toggle, perf ≥30 fps CPU / ≥55 fps WebGL2 at 1280×800.

Each plan file defines scope, non-goals, file changes, validation, and i18n/persistence.
