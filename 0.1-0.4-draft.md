# 0.1 – 0.4 roadmap — gf.html lightweight track

gf.html stays the product: single file, classic `<script>`, no modules, no build, `file://` friendly,
4-language flat i18n table (en/ru/cn/jp), `ResizeObserver` + absolutely-positioned canvases,
`localStorage` settings, animated noise with stable seed and X/Y drift. Painting lives in
`index.html` — never port it.

This roadmap splits the former monolithic 0.1.0 plan into four incremental, reviewable steps. Each
step is lightweight, ships independently, and never ports heavy features from `index.html` or
`ag.html`.

## Sources and stance

- `gf.html` — base. Keep its UX (guide-dot period slider, animation, i18n). Fix its defects, don't
  redesign it.
- `ag.html` — large vanilla SIRDS suite (classes, depth presets, tartan/blobs/tie-dye tiles,
  palettes, Thimbleby μ, HSR, shimmer/wiggle/anaglyph, reticle, export). Useful for content ideas
  and for the correct optical formulas, but its UI shell, class architecture, and injected
  Cloudflare script are not ported. Most of its preset/texture/view buffet is intentionally left out
  to keep gf lightweight.
- `implement-noise-and-brush-tools/` — React+Vite+Tailwind heightmap painter. **Not a SIRDS.** Its
  build setup, `FalloffTable`, brush stamping, `blurShade`, lit renderer (normals/Lambert/Blinn/
  tilt/AO), and `fillNoise` allocation pattern are not ported. Only its noise/height ideas are read
  as reference.
- `index.html` (WebGPU) — fast `sep/std/relax` compute pipelines, brush compute, `DepthMap`/
  `GpuEngine` classes, `StereoGUI` depth carving, shade map, ghost reduction. Heavy and deliberately
  not ported. Lightweight takeaways are distilled per plan; everything else is listed under
  Not ported.

## What counts as heavy (never port to gf.html)

Brushes / painting / `shade` map / `ghost` copies, `FalloffTable`, `heightmap.ts`/`renderer.ts` lit
relief, WebGPU/WebGL compute pipelines, `StereoGUI` bevel carving, save/load webp maps, 5-swatch
palette editors + presets (cyber/forest/…), iterative relaxation (iters 1..60, error
back-propagation), tartan/tie-dye/confetti/wood/blob image tiles with zoom/palette/seed matrix.
They stay in `index.html` / `ag.html`.

## What is taken lightweight (distilled findings only)

- Canvas wrapper with `position:absolute; inset:0` canvases to break layout→resize feedback
  (already in gf, keep).
- Depth as `Float32Array 0..1` single source of truth (replaces red-channel `ImageData` reads).
- Preallocated typed arrays / reuse outside the hot path (no `new` per row/frame).
- Grain quantization after drift (`floor((x-moveX)/grain)`), seeded `hashNoise`/`simplex3` vs
  `Math.random`.
- Geometry sized relative to `w,h` (not fixed pixels).
- `periodAt(z)` single helper for guide dots, drag clamp, status readout and renderer.
- Leftmost-root union-find linking with zero allocations.

## Milestones

### 0.1 — Foundation + defects + canvas drag — shipped
Ten defects fixed, preallocated buffers, `depthF32` source of truth, **link cache** (links depend
only on depth/period/depth-scale, so the animation frame became a pure gather), drag
`dX→period / dY→depth` on the canvas synced to the GUI sliders. CPU only.

### 0.2 — Lightweight depth content — shipped
Presets rewritten scale-invariant and moved into the testable core, plus `heart`, `ripples`,
`pyramid` and an editable text field. Post-process limited to invert + contrast; blur closed, not
deferred.

### 0.3 — Stereo correctness polish — shipped
Leftmost-root union-find (satisfies 100% of stereo constraints where the old overwrite dropped
1–4%), exact two-eye z-buffer hidden-surface removal in one `O(w)` pass, `periodAt` everywhere.
Linear `s = P − z·D` kept, Thimbleby μ still deferred.

### 0.4 — Acceleration — shipped
WebGL2 fragment gather of `texel(root, y)` from the cached root map, CPU fallback, backend select.
Integer hash and tenths grain so white/color can match the GPU byte for byte. No worker: `file://`
blocks them in Chrome. The link-rebuild hitch is 0.5.

### 0.5 — Chunked link rebuild — open
Spread `linkRow` across frames so a slider drag does not freeze a large canvas. Page thread only.

## Tooling that came out of 0.1–0.3

`experiments/` runs the **shipped** code under node by extracting the block between
`// >>> gf-core start` and `// <<< gf-core end` from `gf.html` — no duplicated copy to drift:

- `gf-core.js` — the extractor.
- `sirds-row.js` — separation/linking/pattern invariants.
- `verify-links.js` — audits the rendered image; runs the old naive linker side by side.
- `gf-smoke.js` — stub DOM boots the real `<script>`; catches ids, boot order, wiring.
- `render-png.js` — writes depth/stereogram PNGs for eyeballing without a browser.
- `perf.js` — frame budget table.
- `gl-parity.js` — shader contract against the shipped core; pixel compare when Chrome is present.

Each plan file defines scope, non-goals, file changes, validation, and i18n/persistence.
