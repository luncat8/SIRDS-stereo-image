# 0.1.0 plan — gf.html as the base, port the useful parts of ag.html and Noise Painter

gf.html stays the product: single file, classic `<script>`, file:// friendly, 4-language i18n table (en/ru/cn/jp), draggable guide dots that act as the period slider, animated noise with stable seed and X/Y drift, settings kept in localStorage.

Sources to port from:
- `ag.html`: a large single-file SIRDS app built from classes (depth provider, pattern provider, generator, multi-view renderer).
- `implement-noise-and-brush-tools/` ("Noise Painter"): React + Vite + Tailwind. It is **not a SIRDS**. It draws a lit heightmap. Only its algorithms are worth taking, never its build setup.

Out of scope: every paint/brush feature (brushes, falloff table, shade brush, eraser, stroke interpolation), because painting lives in `index.html`.

## 1. Comparison summary

Verdict: gf has the better base (UX, i18n, animation, guide dots). ag has most of the content: presets, textures, palettes, optical model, post-process, inspector, export, help. Noise Painter adds a terrain generator, a relief preview and colour ramps.

## 2. Defects found in the sources (fix these, don't port them)

- **gf, fixed geometry:** depth presets use absolute pixels (`fillRect(150,120,180,180)`, `arc(460,210,100)`, `110px` font), but the canvas resizes to its container. Size everything relative to `w, h` (ag does this).
- **gf, hot-path allocations:** each row allocates a `new Int32Array(w)` and a `new Array(w)`, `getPatternPixel` returns a new `[r,g,b]` per pixel, and every frame calls `createImageData`. Torus drawing calls `fillRect` once per pixel with a template string. Use preallocated buffers instead.
- **gf, degenerate range:** depth slider max 160 > period min 60, so `stereoShift` clamps to 1 and the image breaks. Clamp depth to `period - minPeriod` (or scale depth as a fraction of the period).
- **gf, stripe texture:** `(val + … + 255) % 255` is an off-by-one wrap. Use `& 255` or `% 256`.
- **ag, Thimbleby period mismatch:** `s = (1-μz)·E/(2-μz)` gives `s = E/2` at z=0 (E=160 → 80 px), yet the guide dots and pattern tile use `E`. Parametrize by the far-plane period `P` (`E = 2P`) so the dots, tile and period slider all match. Also note the depth-factor slider has no effect in Thimbleby mode.
- **ag, "HSR" is not the Thimbleby algorithm:** it compares against the max z of colliding endpoints. It never ray-marches. Implement the real test (see 3.3).
- **ag, blob/confetti textures use `Math.random`:** they are not reproducible and flicker when regenerated. Use a seeded PRNG.
- **ag, wiggle view is broken:** it computes `sx` and never uses it. **Anaglyph is wrong too:** it tints depth luminance instead of building a left/right image pair.
- **ag, allocations:** box blur allocates a scratch `Float32Array` per call, and the generator allocates the output per render.
- **Noise Painter, "random each frame" is broken:** it samples Perlin at integer lattice points, where gradient noise is always 0. Hash-based white noise is the right tool for per-frame randomness.
- **Noise Painter, `fillNoise`:** allocates 4 JS arrays per call and has an unused `norm` path.

## 3. Port list (target: gf.html)

Keep gf's control style, i18n table (add every new string in all 4 languages), `saveSettings/loadSettings`, and guide-dot drag.

### 3.1 Core refactor (prerequisite)
- `depth: Float32Array(w*h)` in 0..1 is the single source of truth. The depth view renders from it. No more canvas red-channel reads.
- Preallocate on resize: `depth`, `depthScratch` (blur), `same: Int32Array(w)`, `out: ImageData` + `Uint32Array` view, and a row colour buffer `rowRGB: Uint32Array(w)`.
- The texture function writes a packed RGBA `Uint32` (no arrays). Per-frame constants are computed once before the row loop.
- Split `buildDepth()` (preset + post-process, runs only when inputs change) from `renderFrame()` (per animation frame).

### 3.2 Depth presets and input
- Rewrite the existing shapes/torus/text so they scale with `w, h`.
- Port from ag: **shark, heart, step pyramid, ripples**, and the **custom text** field for the text preset.
- Port from Noise Painter: **terrain** (fBm Perlin, 4 octaves, lacunarity 2, gain 0.5, scale ≈ 0.025/px scaled to the canvas, normalized to 0..1), plus a **reseed** button (random offset, stored in settings).
- **Load depth image** (a file input, drawn luminance-first with contain fit at 0.9 scale into an offscreen canvas). Keep it in memory only. Saving and loading depth-map files is index.html's job.
- Post-process controls: **invert**, **contrast** (0.2–3, around 0.5), **blur radius** (0–15, separable sliding-window box blur, preallocated scratch).

### 3.3 Stereo core
- Linking: union-find where each root is the leftmost index (`same[i] <= i`), then fill left→right, copying `row[same[x]]`. This replaces the naive overwrite and removes constraint loss.
- **Algorithm select:** `linear` (gf's current: `s = P - z·D`) or `thimbleby` (`E = 2P`, `s = round((1-μz)·E/(2-μz))`, μ slider 0.05–0.8 default 1/3). In Thimbleby mode the depth slider is hidden and μ controls depth. The guide-dot distance is always the far-plane period `P`.
- **Real hidden-surface removal** (toggle, default on), Thimbleby-style: for link (left, right) at depth z, step `t = 1…` while `zt = z + 2(2-μz)t/(μE) < 1` (the linear-mode equivalent uses the separation slope). The link is hidden if `depth[x-t] >= zt` or `depth[x+t] >= zt`. No allocations.
- Keep gf's pattern sampling at the absolute pixel `(x - moveX, y - moveY)`, which is what makes the stable-seed drift work.

### 3.4 Textures
Two families share one `texel(x, y)` hook.
- **Procedural per-pixel** (current gf): white, color, simplex3d, stripes. Add **domain-warped simplex** (warp the coordinates with a lower-frequency simplex, as Noise Painter does, to break up repetitive blotches).
- **Tile-based** (ag approach, tile width = `P`, height = `P`, sampled at `(sx mod P, sy mod P)`, regenerated only when P/palette/seed/zoom changes): **blobs, confetti, tartan, tie-dye, wood**, and an **uploaded image** (repeat pattern, zoom). They use a seeded PRNG (mulberry32 already in gf) so they're deterministic. Animation keeps working through drift and through reseeding each frame when stable noise is off.
- **Palette:** 5 colour swatches and presets from ag (cyber, monochrome, forest, sunset, neon). Add Noise Painter ramps as 3-stop presets (stone, sand, moss, lava, ice, plasma). Swatches expand to 5 by interpolation.
- **Gradient-map option** for simplex/warped textures: map a scalar through the active palette ramp.
- **Zoom/density** slider for the tile textures. Hide the controls that don't apply to the selected texture.

### 3.5 Views (toggle-zone buttons next to Stereogram / Depth)
- **Relief:** a lit depth preview (from Noise Painter's renderer). Normals from central differences, Lambert + ambient + small Blinn specular, mapped through the palette ramp. Light azimuth/elevation are fixed or collapsible. It inspects shape much better than the grey depth map.
- **Anaglyph red/cyan (correct):** synthesize the left/right images by shifting the texture by ±disparity(z)/2, then take R from left and GB from right.
- **Wiggle (correct):** alternate the left/right views every ~150 ms using the same shift, driven by the existing rAF loop (no `setInterval`).
- Animation ("shimmer") already exists in gf: noise animation plus unstable seed. Just add the help tip.

### 3.6 Tools and UX
- **Guide-dots toggle** (default on). Dots stay draggable.
- **Reticle inspector** (toggle): overlay showing cursor x/y, depth z, and local period `s` in px. It uses the same `periodAt(z)` helper as the renderer (single function, no duplicated formula).
- **Export PNG** of the current view, filename `SIRDS_<preset>_<w>x<h>.png`. Guide dots are excluded unless the toggle is on (draw them onto an export copy).
- **Resolution:** `auto` (container, gf's ResizeObserver) or a fixed 1024×640 / 1280×800 / 1920×1080, CSS-scaled to fit. Cap auto size by `min(2, devicePixelRatio)`.
- **Status line:** size + render ms (a moving average; the text is updated at most ~4×/s to avoid per-frame string allocation).
- **Help panel** (collapsible, i18n): ag's 4-step "how to see" + the shimmer tip.

## 4. Not ported
- All brushes / painting / shade map (index.html owns them).
- Noise Painter's React/Tailwind/Vite project, and ag's class-based architecture and slate theme (keep gf's look).
- ag's injected Cloudflare challenge script.
- Noise Painter's tilt/AO knobs beyond what Relief needs.

## 5. Order and validation
1. Core refactor (3.1) + gf defect fixes. Validate: identical output for linear mode at the default settings (hash the pixel buffer before and after in node with a DOM-free render function), and no allocations in `renderFrame` (Chrome allocation timeline flat during animation).
2. Stereo core (3.3). Validate with `experiments/`: a node script that renders a row set and checks every linked pair has equal colour. Measure the period at z=0 == P for both algorithms. HSR on a step depth must produce no echo pixels.
3. Depth presets + post-process (3.2). Validate visually at 3 container sizes (the geometry scales).
4. Textures + palettes (3.4). Validate that tile textures are deterministic for a fixed seed (pixel hash stable across reloads).
5. Views (3.5), tools (3.6), i18n strings for all 4 languages, settings persistence of every new control.
6. Performance: 1280×800 linear + white noise animated ≥ 30 fps on the CPU path. Record it in `experiments/logs/`.

Render functions (depth presets, texel, link/fill) must be pure over typed arrays with a guarded `module.exports` so the node experiments can load them.
