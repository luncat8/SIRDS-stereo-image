# 0.2.0 — gf.html lightweight depth content

Depends on 0.1.0. Single file, no modules/no build, `file://` friendly. Keeps gf lightweight — no painting system, no tile/palette explosion, no views beyond stereogram+depth.

## Goal

Give gf a little more depth variety without bloating it. Rewrite existing presets to be container-relative and add the cheapest pure-math presets plus a custom-text field. Minimal post-process only.

## Non-goals

Image upload, large palette editor, tile-based textures (blobs/confetti/tartan/tie-dye/wood), zoom/density, domain-warped noise, gradient maps, anaglyph/wiggle/relief/tilt, Thimbleby μ slider, heavy blur, save/load maps, WebGL/GPU. All deferred to 0.3–0.4 or left in `index.html`/`ag.html`.

## Findings from index.html — take vs. leave in 0.2

Take: depth as `Float32Array 0..1` (already adopted in 0.1) as single source; geometry relative to `w,h`; scratch-buffer reuse pattern for blur if included.
Leave: `fillNoise` fBm terrain (allocates 4 arrays per call, needs lacunarity/gain/octaves UI), lit renderer, `Heightmap`/`FalloffTable`/`stamp`, `blurShade` passes — not ported. If a terrain preset is desired, implement the tiny fBm inline (4 octaves) without exposing its knobs.

## Changes

### Depth pipeline

- `depthF32: Float32Array(w*h)` stays source of truth (from 0.1). `generateDepthMap` fills it; depth view renders `grey = depthF32[i]*255`; SIRDS reads `z = depthF32[row*w+x]`. No canvas luminance reads.

### Presets (scale-invariant)

Rewrite 0.1 presets to scale:

- `shapes`: rectangle at `(w*0.18, h*0.22, w*0.25, h*0.40)` at `z=0.55`, circle at `(w*0.66, h*0.50, r=min(w,h)*0.14)` at `z=0.95`.
- `torus`: `maxR=min(w,h)*0.31`, `minR=maxR*0.36`, smooth ramp `z = max(0,1-|dist-mid|/thick)*0.90`.
- `text3d`: offscreen text canvas sized `w×h`, font `h*0.28` bold, shadow at `z=0.59`, foreground at `1.0`, sampled to `depthF32` via luminance. All use `w,h` consistently.

Add cheap pure-math presets (pick two to stay light):

- `heart`: classic heart implicit `(hx²+hy²-1)³ - hx²·hy³ ≤ 0` with `hx=(x-cx)/scale`, `hy=-(y-cy)/scale`, `scale=min(w,h)*0.024`. Fill `z=0.2+0.8*edgeDist`, background `0.05`.
- `ripples`: `dist=hypot(x-cx,y-cy)`, `z=0.2+0.7*(cos(dist*0.06)+1)/2*max(0,1-dist/(w*0.55))`.

Optionally add `pyramid` (step pyramid with `steps=5`) if still feels light; no more than three new presets total.

Add **custom text** for the `text3d` preset (lightest content knob):

- `<input type="text" id="depthText" maxlength="12" value="3D LAB">` visible only when `depthPreset==='text3d'`. On `input`, `generateDepthMap` + `updateExecution` + `saveSettings`. i18n label added in all 4 langs. Persisted in `localStorage`. No font picker, no extra canvas.

### Post-process (minimal)

- `invert` (checkbox, `z=1-z`, default off) and `contrast` (`<input type="range" min 0.2 max 3 step 0.1 value 1.0`, formula `(z-0.5)*contrast+0.5` clamped) applied in-place to `depthF32` after preset fill. Both run only when preset/contrast/invert changes, not per animation frame.
- Blur: **not required** to keep 0.2 minimal. If included, cap at `radius 0..6`, separable sliding-window box blur with **one** preallocated `scratchF32` reuse (allocate once at max `w*h`). Hidden/disabled look when `contrast/invert` suffice. Default `0`.

### UI and persistence

- Existing controls keep style/placement. New controls use `.control-group` pattern.
- Extend `I18N` rows for `lblCustomText`, `lblInvert`, `lblContrast` in en/ru/cn/jp. Extend `saveSettings/loadSettings` for `depthText/invert/contrast/blur`. `loadSettings` clamps and hides `depthText` row when preset is not `text3d`.

## Validation

- Visual scale: each preset inspected at 360×240, 700×450, 1280×800 — geometry stays centered and proportionate (no fixed-pixel artifacts).
- Depth math: custom text "HI" vs "3D LAB" produces different depth hashes; invert+contrast round-trip (`contrast=1` vs `contrast=2→invert→invert`) restores approximate shape within 1 LSB.
- Perf: `generateDepthMap` ≤8 ms at 1280×800 for heart/ripples; no per-frame cost (post-process not in `requestAnimationFrame`).
- Persistence: reload keeps preset, custom text, invert, contrast, period/depth/drift settings and language.

## Perf budget

No animation-frame regression vs 0.1. Depth generation runs only on control change or resize; animation path cost unchanged.
