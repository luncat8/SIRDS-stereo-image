# 0.4.0 worklog — WebGL2 gather, CPU fallback

## Review of f130229 (0.1–0.3) before continuing

Re-ran the shipped harness. All of it passed:

- `sirds-row.js` — separation, union-find, HSR no-op on a flat surface, stripe wrap, grain pan
- `verify-links.js` — union-find still satisfies 100% of the stereo constraints; naive overwrite
  still drops 1–4%; HSR still takes hard-edged ghosts to 0%
- `gf-smoke.js` — stub DOM boots the real script, drag, clamp, persistence, static-frame skip

Two small defects, both fixed in this pass rather than left:

- `new Uint32Array(outImg.data.buffer)` ignored `byteOffset`. The view is now
  `new Uint32Array(buffer, byteOffset, w * h)`.
- `--canvas-max-h` was set in the media queries and never read, so a wide viewport grew the canvas
  past the screen. The wrapper width is now `min(100%, max-height * 14/9)`, so the 14/9 ratio holds
  and the image stays in view.

No stereo-math change. The 0.3 linker is the one that shipped.

(node 22, torus, period 100, depth 20, grain 2, before the integer-hash swap. After the swap the
700×450 white frame is 2.3 ms — the mixer is cheaper than `sin` — and the link columns are unchanged.
Full table in `experiments/logs/perf-0.4.0.md`.)

The animation frame is fine at 1280×800 and out of a 16 ms budget once the canvas follows a large
viewport, which the layout does. That is the WebGL2 gather (plan A).

Plan B, a worker for the link rebuild, was not shipped. Chrome blocks workers on `file://`, and this
page is file:// friendly. A worker that only works over http would miss the way the page is opened.
The rebuild hitch is real (40 ms at 1080p, 90 ms at 1440p) and is the next step, on the page thread.

## Plan corrections baked into the archived spec

- `preserveDrawingBuffer: false` blanks a static stereogram — the buffer is cleared after composite,
  and the static-seed path deliberately does not redraw. Shipped `true`. The frame loop is still
  uniforms + `drawArrays`, no allocations.
- Exact white/color parity is impossible with the sin hash. Replaced it with a uint32 mixer whose
  literals are duplicated in the shader and checked by `gl-parity.js`. Grain for those two patterns
  is integer tenths, so float32 and float64 cannot disagree at a cell edge. Simplex and stripe stay
  on the continuous pan and are allowed a tolerance.
- The 2D canvas cannot be `visibility: hidden` while WebGL is showing, or the drag dies (the GL
  canvas is `pointer-events: none`, and a hidden element is not a hit target). It stays at
  `opacity: 0`.

## Steps

1. `hashU32` / `tenthsOf` / `floorDiv` / `grainOrigin` in the core. `texel` uses them for white and
   color. `HASH_BIAS` keeps hashed coords non-negative.
2. Stacked `#glCanvas`. `createSirdsRenderer(canvas)` returns the WebGL2 renderer or the CPU one.
   Link texture is `R32I`, uploaded on rebuild only. Perm table is one `R8UI` of `simplexPerm`.
3. Fragment shader gathers `texel(root, y)` with the y-flip documented in the shader (array row 0 is
   the top, window y = 0 is the bottom, no `UNPACK_FLIP_Y`).
4. Select `auto` / `webgl2` / `cpu`, persisted as `backend`. Badge `⚡ WebGL2` / `CPU (fallback)` /
   `CPU`, moving-average frame time at most 4×/s. GPU time from
   `EXT_disjoint_timer_query_webgl2` when present. `USE_WEBGL2` is the rollback switch.
5. i18n keys in all four languages. Context loss drops to CPU and retries on restore.

## Validation

```
node experiments/sirds-row.js     # grain formula, negative pan, hash, previous invariants
node experiments/verify-links.js  # 100% constraints, unchanged
node experiments/gf-smoke.js      # no WebGL: fallback badge, explicit CPU, backend persisted
node experiments/gl-parity.js     # shader contract against the shipped core
node experiments/perf.js
```

`gl-parity.js` parses the shader block out of `gf.html` and checks every hash literal, `HASH_BIAS`,
the `GRAD` table, the grain formula, the y-flip and the root fetch. A GLSL parser
(`@shaderfrog/glsl-parser`) accepts both shaders; the `gl_*` built-in warnings are expected.

Pixel parity against a real WebGL2 was **not run here** — Chrome could not be downloaded (TLS to the
browser CDN fails in this sandbox). The harness is in `gl-parity.js` and runs when
`puppeteer`'s Chrome binary exists: exact white/color at 700×450 and 1280×800, tolerance logged for
simplex/stripe. Opening the page in a browser is the remaining check; `auto` must show an image
either way, and a blocked WebGL2 must say `CPU (fallback)`.

Rendered depth maps and stereograms still look right (`render-png.js`): shapes, heart, pyramid.
