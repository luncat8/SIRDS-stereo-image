# 0.6.0 worklog — continuous noise speed and standalone painter

## Changes

- Changed `gf.html` noise movement from `frame * speed` sampling to a persistent X/Y offset. Speed sliders now change velocity only; the current noise position remains continuous while a slider is dragged.
- Used the same velocity/offset split in `noise.html`, including a delta-time update, so its relief speed controls do not jump the surface either.
- Added `noise.html`, a classic-script, file-friendly heightmap painter. It keeps the useful ideas from the temporary React prototype without its build/runtime overhead:
  - deterministic value noise and animated displacement;
  - typed-array depth and shade maps;
  - reusable gaussian brush falloff;
  - Add, Subtract, Noise, Shade and Eraser tools;
  - live normal-based lighting, palette presets, terrain reset, clearing, and PNG export.
- Removed `implement-noise-and-brush-tools/` after porting the required behavior.
